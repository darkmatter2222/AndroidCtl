---
name: androidctl-workbench
description: Start and operate the local AndroidCtl web device utility and its authenticated JSON API.
---
Read `docs/web-workbench.md`. Start `python -m androidctl.web --no-browser` from an installed package, or with `PYTHONPATH=src` in this checkout. Keep the process running; the command prints the local URL with a per-process token. Do not put this token or wireless pairing codes into committed files or logs.
Use the exact serial from `/api/devices`. Supply `X-AndroidCtl-Token` for API requests. Configure `--adb-port 5038` only when intentionally using AndroidCtl's managed host ADB server; desktops use 5037. Read-only inspection is safe alongside workers. Obtain ownership of the device before any input, disconnect, or native scrcpy interaction. Do not change emulator lifecycle as a side effect of opening the workbench. Never claim screenshot polling is video or that launch success proves the desktop viewer is healthy.

For display changes, read `display` profiles first; use `resolution` for immediate changes or `restart` to reboot and apply after boot. Poll device `operation` until done/error and keep the server alive. Coordinate input ownership before changes; reacquire screenshots afterward. Prefer the browser Pause tile control when only preview overhead should stop. Network disconnect affects the shared ADB transport; USB disconnect detaches only this workbench. See the restart/resolution section in the guide for native versus current resolution and host-startup reset limitations.

For VM lifecycle, configure a host via `/api/host-action` and scan it first. Use host/instance IDs for start/stop/create/delete; use exact ADB serials only for screen/input actions. Poll `/api/hosts` job results; a command timeout does not prove the remote command was canceled. Deleting requires explicit userdata choice and exact DELETE ID confirmation. For performance, collect the read-only host diagnostics, stop unused VMs, then trial one stopped VM with the host renderer and verify GPU activity. Do not claim measured performance or unload unidentified model processes. Read docs/gpu.md for NVIDIA prerequisites and rollback.
